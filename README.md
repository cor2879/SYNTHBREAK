# SYNTHBREAK

A neon arcade breakout game created by **Andrew Cole**.

## Play

SYNTHBREAK is a browser game built with HTML5 Canvas and JavaScript. The current build supports desktop and mobile play.

### Controls

**Desktop**
- Mouse or Arrow Keys — Move paddle
- Space — Launch ball
- P / Escape — Pause
- Z / Click — Fire laser when the laser powerup is active

**Mobile**
- Drag — Move paddle
- Tap — Launch ball / activate menu controls
- Tap and hold — Fire laser when the laser powerup is active

## Features

- 100 levels across 10 zones
- Normal and Hard modes
- Boss encounters
- Enemy types and projectiles
- Powerups and a pre-level shop
- Local high scores
- Responsive mobile canvas and touch controls
